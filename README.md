# Sistema de Inventario Oficina VEN-911

## 1. Instalaciones necesarias

-   Nodejs20+
-   MySQL v8.0

## 2. Configurar Base de datos

Abre el MySQL Command Line Client y ejecutar la siguiente sentencia para crear la base de datos

```
    CREATE DATABASE sys_ven911;
```

> **¡IMPORTANTE!** el nombre debe ser **sys_ven911**

## 3. Instalar paquetes

Abre la terminal (cmd) y navega hasta la carpeta del proyecto, una vez allí ejecutar el siguiente comando en la terminal

```
    npm install
```

Esto instalara todos los paquetes para el desarrollo del sistema

## 4. Ejecutar Proyecto

Al finalizar la instalación de los paquetes, ejecutar el siguiente comando para arrancar el proyecto

```
    npm run dev
```
